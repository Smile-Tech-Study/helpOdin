Добавлено ограничение по объему хранилища на индивидуальном тарифе.

![](./ogranichenie-po-obemu-khranilischa.png){width=1058px height=470px}

При попытке сохранения файлов при превышении лимита в любых библиотеках организации, при отправке решения заданий, при отправке файлов в чатах, относящихся к организации, показывается  красное предупреждение с текстом: "Невозможно добавить материал, превышен лимит хранилища организации"

На странице "Мой тариф» добавлено отображение по ограничению хранилища.
